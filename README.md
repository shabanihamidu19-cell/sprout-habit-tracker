# Sprout — Habit Tracker

Calm habit & life tracker. **Progress over perfection.**

## Jinsi ya kufungua kwenye simu

1. Download faili **Sprout-Habit-Tracker.html** (kutoka chat au repo hii).
2. **Android:** Fungua kwa Chrome → menu (⋮) → **Add to Home screen** / Ongeza kwenye skrini ya mwanzo.
3. **iPhone:** Fungua kwa Safari → Share → **Add to Home Screen**.

App inafanya kazi **bila internet**. Data yote inakaa kwenye simu yako tu.

## Features

- Today dashboard (one-tap complete)
- Flexible schedules
- Streaks & consistency calendar
- Goals, reflections, insights
- Export / import (JSON + CSV)

No account. No tracking.
